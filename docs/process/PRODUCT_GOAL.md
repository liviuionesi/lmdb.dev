# Product Goal

The single overarching objective the whole Product Backlog serves (Scrum
2020): a self-hosted, TMDB-shaped microservices platform that demonstrates
production-grade backend/frontend/cloud/observability practice — real
enough to run and demo, disciplined enough to defend in a technical
interview — built at $0 real cost (ADR-004).

Epics exist to deliver a piece of this goal. A Story that doesn't trace
back to it, even loosely, is probably out of scope.

## Roles

- **Product Owner / Scrum Master**: the repo owner (Liviu) — decides what
  matters, approves architecture and scope changes, can pause the process
  at any time.
- **Developers**: the Claude Code agents (interactive sessions and the
  scheduled autonomous routine) — implement, test, review, and close
  Stories/Tasks against this Product Goal.
